## Official Apps

Telegram is a free, cloud-based messaging app with optional end-to-end encrypted chats, voice and video calls, and file sharing.

- __Mobile__ : [Android](https://telegram.org/android), [iPhone and iPad](https://telegram.org/dl/ios).
- __Desktop__ : [Windows, macOS and Linux](https://desktop.telegram.org/), [macOS (native)](https://macos.telegram.org/).
- __Web__ : [Telegram WebK](https://telegram.org/dl/webk), [Telegram WebZ](https://telegram.org/dl/webz).
